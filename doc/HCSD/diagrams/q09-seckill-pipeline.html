为什么 Lua 而不是分布式锁

  • 锁：加锁 + 解锁两次网络往返，其余线程自旋
  • Lua：一次往返，Redis 单线程执行脚本天然串行
  • 脚本要短（长脚本阻塞全部请求）；集群模式 key 需同 slot

闭环补数（必答项）

  • 预扣成功 + 订单失败 = 少卖，与超卖同为资损
  • 延迟消息回补库存 + 对账 job 兜底差异
  • 下单去重：唯一业务单号

Redis 与 DB 的一致性定位

  • Redis 是资格判定层，不是账本
  • 最终账以 DB 为准，差异由对账修正
  • 表述为"按层次退化"，不是"缓存绝对正确"
