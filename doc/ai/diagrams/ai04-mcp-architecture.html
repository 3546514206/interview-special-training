MCP 解决了什么问题？

  • M×N 问题：M 个 LLM × N 个工具 = M×N 适配
  • MCP 把 N 个工具收成统一 Server → M+N
  • 类似 LSP（语言服务器协议）：编辑器×语言 = M×N → LSP 后变 M+N
  • 类比：USB-C、LSP、ODBC、SQL
  • Anthropic 2024-11 开源，OpenAI 2025 跟进

三原语：Tools / Resources / Prompts

  • Tools：可执行动作（函数），LLM 主动调用
  • Resources：可读取数据（文件 / DB / API），由 Client 注入而非 LLM 调用
  • Prompts：可复用 prompt 模板，用户手动触发
  • Tools = 主动；Resources = 被动；Prompts = 用户
  • 三者通过 JSON-RPC 暴露，Client 启动时发现（tools/list / resources/list / prompts/list）

实际开发一个 MCP Server

  • 用 Python：mcp.server + @server.tool() 装饰器
  • 用 TypeScript：@modelcontextprotocol/sdk
  • 传输：stdio（本地）/ SSE（远程）/ Streamable HTTP（新）
  • Client 配置：claude_desktop_config.json 或 Cursor MCP 配置
  • 官方 Server 库：Filesystem / GitHub / Postgres / Slack / Puppeteer 等

面试加分点

  • 能画出来：Host / Client / Server 三层关系 + JSON-RPC
  • 说清三原语：Tools 主动 / Resources 被动 / Prompts 模板
  • 对比 Function Calling：标准 vs 私有、M+N vs M×N
  • 类比 LSP：让面试官秒懂
  • 说局限性：新协议、生态未成熟、多一层网络延迟
