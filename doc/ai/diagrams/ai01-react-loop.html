OpenAI / Anthropic 通用

Thought（思考）

  • LLM 内部推理，不下发给外部
  • 拆解任务：现在该用什么工具、参数是什么
  • ReAct 区别于 CoT 的关键：Thought → Action 显式配对
  • 无 Thought → 工具调用乱跳、有幻觉

Action（行动）

  • 输出 结构化 JSON（不是自然语言！）
  • 受 JSON Schema 约束，参数类型/必填校验
  • 可执行：调工具 / 查 RAG / 调子 Agent
  • Action 不存在 → LLM 自由对话 → 易幻觉

Observation（观察）

  • 工具执行的真实返回，注入回 Prompt
  • 下一轮 Thought 必须基于 Observation，不能跳步
  • 超时空值 / 报错 → 触发重试或用户反馈
  • Observation 是「控幻觉」的关键

为什么 ReAct 控幻觉？

  • 答案必须由 Observation 拼装，不能凭空
  • Thought 强制外显化，可被 prompt 拦截
  • 工具失败 → 必须重新思考，不能编
  • Plan-and-Execute 缺 Observation → 早期版本易幻觉
