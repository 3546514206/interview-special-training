执行 UPDATE

redo log · 物理日志

  • • 记录页号 + 偏移 + 修改，WAL
  • • 事务执行中持续写 redo buffer
  • • 提交时刷盘（flush_log_at_trx_commit）
  • • 崩溃恢复从 checkpoint 重放
  • • 2PC：prepare → commit 标记

undo log · 逻辑日志

  • • 记录旧值/反向操作
  • • 未提交事务回滚
  • • MVCC 版本链 + Read View
  • • purge 线程清理旧版本
  • • 长事务会阻塞 purge

binlog · Server 层逻辑日志

  • • ROW 格式记录前/后镜像
  • • 2PC 第二阶段写入并 fsync
  • • 复制：从库 IO 线程 → relay log
  • • PITR：mysqlbinlog 重放
  • • 与 redo 靠 2PC 保持一致

2PC 崩溃判断

  • • redo prepare + binlog 不完整 → 回滚
  • • redo prepare + binlog 完整 → 提交
  • • redo commit → 直接提交
  • • 双 1：sync_binlog=1 + flush=1
  • • group commit 合并 fsync 开销
