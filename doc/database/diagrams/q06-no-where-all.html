易错点（面试高频）

  • • ❌「没 WHERE 也能用索引」→ ✅ 没有过滤条件 = 全表扫 = type=ALL
  • • ❌「type=ALL 必是慢 SQL」→ ✅ 看 rows + 表大小，百万行小表 ALL 可能合理
  • • ❌「全表扫 = 必须回表」→ ✅ 走 PK 树全表扫 = 顺序读完整行，不需要回表
  • • ❌「SELECT * 走 PK 树就能避免回表」→ ✅ 仅当 WHERE PK 时成立，无 WHERE 也是
