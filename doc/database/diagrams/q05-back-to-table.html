易错点（面试高频）

  • • ❌「二级索引存的就是行数据」→ ✅ 只存主键，必须回表
  • • ❌「InnoDB 主键索引是非聚簇」→ ✅ 主键索引就是聚簇，叶子就是数据本身
  • • ❌「回表 = 内存拷贝」→ ✅ 是磁盘随机 I/O，每行一次寻道
  • • ❌「覆盖索引 = 主键索引」→ ✅ 任意索引能含查询列就算
