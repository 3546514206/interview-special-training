核心原理

  • 本质：联合索引 idx_name_age 按 (name, age) 整体排序，叶子存 (name, age) + 聚簇 id
  • 排序规则：先按 a 排序，a 相同按 b 排序，b 相同按 c 排序
  • 最左前缀：从最左列开始匹配，不能跳过中间列，但可以只用前缀列
  • 范围截断：遇到范围查询 b > 2 后，b 之后的 c 就走不到索引

失效原因

  • 跳过头部列：WHERE b=2 没 a → b 在链表中无序 → 全表扫
  • 中间列断层：WHERE a=1 AND c=3 a 走，c 失效（c 不能跳过 b）
  • 范围断后：WHERE a=1 AND b>2 AND c=3 b 用范围后 c 失效
  • 失效根本原因：破坏 B+ 树的有序性

实战建议

  • 列顺序：区分度高 + 常用等值放前，范围列放最后
  • 建索引：(a, b) ≠ (b, a) → 顺序就是「最左」
  • 覆盖索引：经常查 (a, b) → 直接命中，不回表
  • 验证：EXPLAIN 看 key_len 算出用了几列
