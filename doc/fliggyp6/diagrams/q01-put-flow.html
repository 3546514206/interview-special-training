紫色 = 数组格子（桶） 绿色 = 本次新来的 key 灰色 = 链上已有的节点 黄色 = 被覆盖/替换的值 青色 = 放大镜正在看的桶

六步口诀

  • • 扰动算指纹（高 16 位异或进低 16 位）→ 位与算柜号（&15 代替 %16）
  • • 桶空 直接放；同 key 覆盖 value；不同 key 尾插排队
  • • 链长 ≥8 且数组 ≥64 → 转红黑树；件数过门槛 → 扩容翻倍

为什么查得快

  • • 定位桶是一次位运算（不用从头找）
  • • 桶里最多几件（负载因子 0.75 保证），链短摸几步就到
  • • 最坏变长链 → 树化兜底 O(logN)：从"摸链"变"查树"
