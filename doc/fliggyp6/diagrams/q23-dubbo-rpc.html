紫色 = Registry 注册中心（问路处） 青色 = Consumer 消费者（发起调用） 绿色 = Provider 提供者（真正干活） 橙色 = Monitor 监控中心（记考勤） 黄色 = 线上数据 / 报文

启动三步

  • • ⓪ 注册（提供者挂牌）→ ① 订阅（消费者要名单）→ ② 推送（地址入本地缓存）
  • • 注册中心只管问路：真正调用走 ③ 号线直连，不经过它
  • • 提供者宕机 → 临时节点消失 → 自动摘除；注册中心挂了 → 本地缓存照常调

调用穿十层

  • • 消费者侧：代理 → 集群(选机器) → 过滤 → 编码序列化 → Netty
  • • 提供者侧：解码 → 线程池 → 过滤 → 反射真方法，响应原路返回
  • • 一条 TCP 长连接多路复用，靠 requestId 配对：同步调用 = 伪同步

面试高频

  • • 注册中心全挂？→ 能调（直连 + 内存/磁盘缓存）
  • • 默认容错 failover 重试 2 次 → 写操作注意幂等
  • • IO 线程只收发，业务进线程池（fixed 200）——慢调用不拖垮网络
