Q6 · ThreadLocal 内部结构与泄漏真相

从 Thread 出发：值到底存在哪、弱引用保护了什么、线程池如何把问题放大。弱引用不是防泄漏开关——它只保护 key，不保护 value。

STEP 01 / 06

值不在 ThreadLocal 里，而在 Thread 里

结构真相

  • • 值存在 Thread.threadLocals，不在 ThreadLocal
  • • 链路：Thread → ThreadLocalMap → Entry[] → value
  • • key = ThreadLocal 实例（弱引用）
  • • 每个线程一份 map，天然线程隔离

泄漏真相

  • • 弱引用只回收 key，不回收 value
  • • key=null 的 Entry 仍被 table[] 强引用
  • • 线程池 worker 不退出 → 引用链常驻
  • • static final 忘记 remove → 泄漏 + 串号

正确姿势

  • • static final ThreadLocal + finally remove()
  • • 不要每次任务 new ThreadLocal
  • • 跨线程用 TTL；Java 21 可看 ScopedValue
  • • get/set 的顺手清理不能依赖
