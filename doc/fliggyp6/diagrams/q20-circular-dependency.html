Q20 · Spring 三级缓存与循环依赖

三级是核心：ObjectFactory 延迟决策，保证 B 拿到的早期引用 == A 最终暴露的引用（AOP 代理一致性）

三级各存什么

  • • 一级：完整 Bean（对外暴露）
  • • 二级：工厂执行后的早期引用
  • • 三级：ObjectFactory（延迟决策）

为什么必须三级

  • • 二级能解普通循环，解不了 AOP 一致性
  • • 工厂把"是否代理"推迟到被需要那一刻
  • • B 拿到的 == 容器最终暴露的引用

救不了的情况

  • • 构造器注入循环 → BeanCurrentlyInCreationException
  • • prototype 作用域（不进缓存）
  • • Spring Boot 2.6+ 默认禁止循环依赖
