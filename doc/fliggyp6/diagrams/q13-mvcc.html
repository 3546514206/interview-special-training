Q13 · MVCC 原理

隐藏字段 + undo log 版本链 + Read View · RC 每次快照新建视图，RR 全程复用

三要素

  • • 隐藏字段：DB_TRX_ID / DB_ROLL_PTR / DB_ROW_ID
  • • undo log 版本链（roll_ptr 串旧版本）
  • • Read View 四字段 + 5 条可见性规则

RC vs RR 一句话

  • • RC：每次 select 新建 Read View → 不可重复读
  • • RR：第一次 select 生成后全程复用 → 可重复读
  • • RR 防幻读 = MVCC（快照读）+ Next-Key Lock（当前读）

易错点

  • • MVCC ≠ 无锁：快照读无锁，当前读仍有锁
  • • undo 清理由 purge 线程异步做，与事务结束无关
  • • MVCC 不解决写冲突（写冲突靠锁）
