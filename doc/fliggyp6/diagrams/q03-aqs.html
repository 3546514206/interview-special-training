Q3 · AQS 原理

volatile state + CLH 变体双向队列 + CAS —— JUC 一切锁与同步器的骨架（框架，不是锁）

三大核心

  • • volatile state（子类定语义）
  • • CLH 变体双向队列（管等待者）
  • • CAS（原子改 state / 挂节点）

公平 vs 非公平

  • • 公平：acquire 先查队列有无等待者
  • • 非公平：上来直接 CAS 抢（可插队）
  • • 非公平吞吐高：减少线程切换

追问怎么接

  • • "Latch vs Barrier？" → 一次性 vs 可循环 reset
  • • "Condition？" → await 出队 / signal 回队
  • • 手写 20 行互斥锁 = tryAcquire + tryRelease
