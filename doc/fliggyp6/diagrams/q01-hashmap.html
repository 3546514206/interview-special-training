Q1 · HashMap 底层实现

两大卡点：树化要"链表 ≥8 且数组 ≥64"双条件；扩容用 hash & oldCap 拆链，不重新 hash

卡点一：树化双条件

  • • ❌ "链表 ≥8 就转树" → 还要数组 ≥64
  • • 数组 <64：只扩容（把链表摊薄）
  • • 退化阈值 6 不是 8：留滞后防反复横跳
  • • 8 的来源：泊松分布，链长 8 概率亿分之六

卡点二：扩容重定位

  • • hash & oldCap == 0 → 原位 j
  • • == oldCap → j + oldCap
  • • 不重新 hash，链表拆两半各挂各的
  • • 前提：容量是 2 的幂

易错点

  • • 2 的幂主因是位运算快，不是均匀
  • • 0.75 = 时间-空间平衡，非玄学
  • • 树化只救查询，put 反而更慢
  • • 实验：改容量 64 阈值看树化时机变化
