第13次put触发 → 32格新表 → 桶1拆两条（hash&oldCap 分流 · 尾插保序）→ 归位交接（数字来自 Q01HashMapLab 实验5）
1 / 11 ← → 键翻页 · 每帧一小步

触发与翻倍

  • • ++size > threshold（严格大于：12 件不扩、13 件才扩）
  • • 触发后 capacity ×2、threshold ×2（16/12 → 32/24）
  • • 扩完只装 41% → 单次 put 永远只扩一次 → 均摊 O(1)

分流免 rehash

  • • 只看 hash 的 oldCap 那一位（16）：0 → 原位，1 → 原位+16
  • • 新下标 hash&31 只比旧下标 hash&15 多看这一位
  • • 位运算代替重新取模，一条长链拆两条短链

尾插保序

  • • loTail / hiTail 尾插，链内顺序不变（preserve order）
  • • JDK7 头插搬一条链 = 反转一条链 → 并发成环
  • • 单线程下每节点只搬一次，结构性成不了环
