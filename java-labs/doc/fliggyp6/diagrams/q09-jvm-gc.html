新生代 · 复制算法

  • • Eden 满 → Minor GC：可达性分析，存活者复制进 to 并 年龄 +1
  • • Eden + from 整块丢弃：无碎片、存活少时极快，然后 from/to 互换
  • • 晋升三条通道：阈值 15（对象头 4bit）/ 动态年龄（同龄 > S 一半）/ 大对象直入

老年代 · 标记-整理

  • • Minor GC 前空间担保：老年代可用 < 历次晋升平均 → 先 Full GC
  • • Old 满 → Full GC：标记 → 清除 → 整理压缩（无碎片），整堆 + Metaspace
  • • Full GC 后仍放不下 → OutOfMemoryError（先 dump 再排查）

高频追问三连

  • • 为何两块 Survivor？复制免碎片；HotSpot 用 10% 空间换掉经典算法的 50%
  • • 为何 Eden 这么大？多数对象朝生夕死，死在 Eden = 随整块丢弃、零成本
  • • 年龄上限为何 15？对象头只留了 4 个 bit（0~15）
