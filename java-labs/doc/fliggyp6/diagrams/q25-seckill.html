Q25 · 秒杀系统五层架构

热点隔离 / 动静分离 / 分层削峰 / 异步化 / 兜底预案 —— 每层都是漏斗，DB 只见 100 单

五大原则

  • • 热点隔离：秒杀独立域名/集群/DB
  • • 动静分离：静态走 CDN，动态走缓存
  • • 分层削峰：层层漏斗过滤
  • • 异步化：核心链路只做预扣
  • • 兜底预案：限流降级熔断静态化

防超卖三阶段

  • • Redis Lua 预扣（原子，无 RTT）
  • • DB WHERE stock>0 二次校验
  • • 支付超时延迟队列回滚

易错点

  • • ❌ "先 DB 扣库存" → DB 扛不住并发
  • • ❌ "Lua 比锁快 10 倍" → 无固定倍数，取决于网络 RTT
  • • ❌ "MQ 一定不丢" → 同步刷盘+主从同步才不丢
