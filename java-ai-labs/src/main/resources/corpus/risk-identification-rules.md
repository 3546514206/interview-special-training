# 风险识别规则

平台的风险识别规则覆盖 5 个维度：市场风险、流动性风险、估值风险、操作风险与合规风险。五个维度必须在每只接入产品上全部完成打分，缺项视为合规风险未识别。

风险等级分为 R1 到 R5 共五档，R1 最低、R5 最高。风险等级由产品条款自动判定，人工复核不得下调等级，只能上调。

净值预警线按风险等级分档：R1 与 R2 产品的单月净值回撤达到 5% 触发黄色预警，达到 10% 触发橙色预警；R3 与 R4 产品的对应阈值下调为 3% 与 6%；R5 产品只要出现单月回撤即直接触发橙色预警。

集中度预警阈值为单一持仓占组合比例 30%，单一发行人占组合比例 20%，任一阈值被触发后系统自动冻结该产品的新增申购，直到人工复核解除。

流动性风险识别的硬性要求是：单日赎回申请超过基金规模 10% 的部分按比例确认，剩余部分顺延处理，顺延期限不超过 15 个工作日。
