# 数据权限与脱敏

平台数据权限分为 3 级：公开级、内部级与机密级。每条数据在入库时必须标注权限级别，机密级数据的访问需要单独授权，授权有效期最长为 90 天。

脱敏规则按字段类型定义：手机号保留前 3 位和后 4 位，中间 4 位以星号掩码；身份证号保留前 6 位和后 4 位；银行卡号只保留后 4 位；客户姓名保留姓，其余字符用星号替代。

姓名、手机号、身份证号三类字段默认不出现在导出文件中，确需导出时需提交审批，审批通过后文件自动添加水印并在 24 小时后失效。

查询与导出行为全量留痕，日志保留 180 天；批量导出单次不得超过 10000 条记录，超过时必须走离线审批流程。

数据权限与脱敏策略变更需经过安全委员会评审，评审周期为每季度一次。
