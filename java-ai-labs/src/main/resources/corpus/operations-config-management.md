# 运营配置管理

运营配置分为三级：全局配置、业务线配置与租户级配置。同名配置项的优先级为租户级最高、全局配置最低，冲突时按就近原则生效；未显式配置时回落到全局默认值。

配置变更走「申请、审批、灰度、全量」四步流程。审批采用三级审批制：一般配置由业务线负责人审批；核心配置（涉及费率、风控阈值、权限）需要二级审批；涉及资金流与对客展示的配置必须经过三级审批并由合规会签。

灰度发布按 10%、50%、100% 三档推进，每档观察窗口为 30 分钟，观察期内指标异常自动回滚。回滚要求 15 分钟内完成，配置平台通过版本快照实现一键回滚。

所有配置变更记录留存 3 年，包含变更人、审批人、变更前后取值与生效时间。生产环境配置变更禁止在业务高峰期执行，窗口期为每日 22:00 至次日 6:00。
