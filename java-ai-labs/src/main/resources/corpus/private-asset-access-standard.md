# 私募资产接入准入标准

私募资产接入平台的管理人准入标准由三条硬性门槛构成，缺一不可。

第一条是资本门槛：管理人的实缴资本不低于人民币 1000 万元，且注册资本必须已经实缴，不接受认缴额度。第二条是经营年限：管理人成立满 3 年，并且管理规模不低于 5 亿元人民币。第三条是业绩要求：最近 3 年的年度审计报告需要由具备证券期货业务资格的会计师事务所出具，且管理规模不得出现连续两年下降。

在产品层面，单只私募基金的初始实缴规模不低于 1000 万元人民币，单一投资者持有份额占比不得超过 50%，机构投资者与个人投资者必须分别建账、分别披露，禁止混同运作。

准入审核由合规部与风险部联合执行，全流程 5 个工作日内出具结论，结论分为通过、有条件通过、否决三种。有条件通过必须明确整改事项与整改期限，整改期限最长不超过 30 个工作日。

接入后的持续监测每季度执行一次，重点关注实缴资本变动、主要人员离职与管理规模变化；任一情形触发预警的，平台有权暂停该管理人的新增申购权限。
