# 私募资产结算与托管规则

私募资产的结算与托管规则由托管人与平台共同执行，与管理人自身的准入标准是两套独立制度。

基金估值频率为每周五，估值方法采用最近一期已披露的净资产口径。投资者申购确认时间为 T+1，赎回款项划付时间为 T+2，遇节假日顺延。

托管费按基金资产净值的 0.05% 年度计提，管理费按 1.5% 年度计提，业绩报酬按超额收益的 20% 计提，三项费用合计不得超过 2.5%。

单一私募基金的管理规模上限为 10 亿元，超过规模上限后不得继续接受申购，存量投资者不受影响。

基金份额登记由管理人负责，登记数据与托管账目每日对账，差异超过 0.01% 必须在 2 个工作日内查明原因并出具说明。
