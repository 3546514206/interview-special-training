# 资产配置服务

面向高净值客户的资产配置服务采用「战略配置加战术再平衡」两层结构。

战略配置层给出目标比例：股票类资产占 30% 以内，债券类资产占 40% 到 60%，另类投资占 10% 到 20%，现金及现金等价物占 5% 到 15%。四类比例之和必须等于 100%，系统在提交前会强制校验，比例不平直接拒绝落单。

战术再平衡层的触发条件有两条：任一大类资产偏离目标比例超过 5 个百分点，或者组合近一年回撤超过 8%。触发后系统生成调仓建议，经投顾复核后执行；常规调仓周期为每季度一次，紧急情况下可以临时加仓。

组合风险指标按月出具报告，包含波动率、最大回撤、夏普比率三个口径。其中最大回撤的预警线为 8%，强制降仓线为 12%，触发强制降仓时股票类资产敞口必须压降到 15% 以内。

所有配置方案在执行前必须做「适当性校验」：方案的最大回撤估计不得高于客户风险承受等级对应的上限，校验不通过时只能降档执行。
